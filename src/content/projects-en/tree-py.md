Want a bit of color on your desktop for the holidays? `tree.py` is a Christmas tree you code in Python but can fully customize.

## Why I built it

In December 2023 at the office someone said "let's buy a Christmas tree". I said "don't — I'll code it". When they took me seriously I felt a bit embarrassed, but a glowing tree in the terminal came out of it. The real reason: everyone had the same plastic trees and LEDs. I wanted the color, size and ornaments to live in my code — and I open-sourced it so friends could build their own.

![tree.py configuration and render flow](/diagrams/tree-py.svg)

## What it does

An interactive, customizable Christmas tree rendered in terminal or a window. Colors, ornaments, star — all yours.

## Install

```bash
git clone https://github.com/bymfd/tree.py.git
cd tree.py
python tree.py
```

## Customize

Change the tree's color, size and ornaments. The code is simple and readable — a few lines give you a minimalist or over-the-top tree.

## Why?

Because coding a Christmas tree is more fun than buying one. And you get to tell your friends "I wrote it".
